================================================================================
SpecForge - ローカル起動・オフライン利用ガイド
================================================================================

Q. なぜZIPを解凍して index.html を直接ダブルクリックすると何も出ない（真っ白）なのか？
--------------------------------------------------------------------------------
本アプリは React / TypeScript / Vite によるモダンWebアプリケーションです。
通常のブラウザは、セキュリティ上の厳格な制限（CORSポリシーおよび file:// プロトコル制限）により、
ローカルのハードディスクから直接スクリプトファイル（.js / .mjs / .tsx）を読み込むことをブロックします。
そのため、直接ダブルクリックすると画面が真っ白になってしまいます。

これを完全にオフラインで、デスクトップアプリとして快適に利用するには、
以下の「方法A（推奨・最も簡単）」または「方法B」のいずれかをご利用ください。


================================================================================
【方法A】ブラウザから「デスクトップアプリ」としてPCに直接インストールする（推奨）
================================================================================
※ インストール後はインターネット回線を切断しても完全オフラインで永続利用できます。
※ Node.jsなどの追加ソフトのインストールは一切不要です。

手順：
1. Google Chrome または Microsoft Edge で、本アプリの共有URL（または開発URL）を開きます。
2. ブラウザのアドレスバーの右端に表示される「アプリをインストール」アイコン（パソコン画面と下矢印のマーク）をクリックします。
   （またはブラウザの右上メニュー「...」→「アプリ」→「SpecForge をインストール」）
3. デスクトップ上に「SpecForge」の専用アイコンが作成されます。
4. これ以降は、デスクトップのアイコンをクリックするだけで、独立した専用ウィンドウでアプリが起動します。
   すべてのプログラムがPC内にキャッシュされるため、オフラインでも高速に動作します。


================================================================================
【方法B】ダウンロードしたZIPフォルダからローカル起動する場合（開発者・PC管理者向け）
================================================================================
PCに Node.js (https://nodejs.org/ja) がインストールされている環境であれば、
付属のスクリプトで1クリック起動できます。

手順：
1. ZIPファイルを展開したフォルダ内にある「起動する.bat」（Windows）をダブルクリックします。
2. 自動的にローカルサーバーが起動し、ブラウザ（http://localhost:4173）でアプリが開きます。
3. Mac/Linux環境の場合は、ターミナルで `./start.sh` または `npm run preview` を実行してください。

※ 起動後は完全ローカル環境で動作し、社内共有フォルダのJSON同期やPDF読み取りもすべてオフラインで動作します。
